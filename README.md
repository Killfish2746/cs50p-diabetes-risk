این برنامه با استفاده از **معیارهای بالینی استاندارد**، فاکتورهای ریسک را تحلیل کرده و نتیجه را در سه سطح طبقه‌بندی می‌کند. هدف از این پروژه، پیاده‌سازی منطق‌های شرطی (Conditional Logic) و توابع در پایتون با رویکردی کاربردی و علمی است.

## 🚀 نحوه نصب و اجرا

### پیش‌نیازها
برای اجرای این پروژه، به **پایتون نسخه 3.8 یا بالاتر** نیاز دارید. این پروژه از هیچ کتابخانهٔ خارجی (External Library) استفاده نمی‌کند و فقط بر پایهٔ کتابخانه‌های استاندارد پایتون است.

### اجرای برنامه
پس از انتقال به پوشهٔ پروژه، دستور زیر را در ترمینال اجرا کنید:

```bash

```

### اجرای تست‌ها (pytest)
برای اطمینان از صحت عملکرد منطق‌های برنامه، مجموعه‌ای از تست‌های خودکار طراحی شده است. برای اجرا از دستور زیر استفاده کنید:

```bash
pytest test_project.py
```

## 🔧 منطق بالینی و توابع اصلی

برنامه بر اساس استانداردهای زیر طراحی شده است:

| تابع | توضیحات |
|------|---------|
| `calculate_bmi(weight, height)` | محاسبه شاخص توده بدنی (BMI) |
| `classify_glucose(level)` | تعیین وضعیت قند خون (نرمال، پیش‌دیابت، دیابت) |
| `assess_diabetes_risk(...)` | محاسبه امتیاز نهایی ریسک (Risk Score) |

### جدول امتیازدهی ریسک
برنامه بر اساس متغیرهای زیر به کاربر امتیاز می‌دهد و در نهایت سطح ریسک (Low/Moderate/High) را اعلام می‌کند:

| پارامتر | شرط | امتیاز |
|:---:|:---:|:---:|
| **قند خون** | ۱۰۰ تا ۱۲۵ (پیش‌دیابت) | +۳ |
| **قند خون** | ۱۲۶+ (بالا) | +۵ |
| **BMI** | ۲۵ تا ۲۹.۹ (اضافه‌وزن) | +۱ |
| **BMI** | ۳۰+ (چاقی) | +۳ |
| **سن** | ۴۵+ سال | +۲ |
| **سابقه خانوادگی** | مثبت | +۲ |
